# @fresh-cup/mobile

Fresh Cup Android + iOS app (Expo / React Native, expo-router). Part of the
Fresh Cup Juice House monorepo — see the root [`README.md`](../../README.md)
and [`docs/`](../../docs) for architecture and setup instructions.

```bash
pnpm install                        # from the monorepo root
pnpm --filter @fresh-cup/mobile dev # opens Expo dev tools
```
